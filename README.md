# StudyCenter Public

Local-first study organisation for TU Graz students. Each installation starts
empty and uses its owner's accounts. Keep tasks, notes, dates and original source
evidence together in a local application.

Development is in progress. Installable release files will be linked here after
their platform and content checks; there is currently no released installer.

Source synchronisation is manual. AI connections are optional and may incur
provider charges when used. There is no automatic telemetry or shared cloud.
