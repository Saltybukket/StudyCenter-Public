# Delivery plan

Target: v0.1.0-beta.1, AGPL-3.0-only, Windows x64 setup and Ubuntu 24.04 x64 package.

| Milestone | Scope | State |
|---|---|---|
| M0 | Independent repository, license, publication checks | in progress |
| M1 | Empty portable core, source facts, actions, secrets, backups | pending |
| M2 | Shared model contract and explicit account connections | pending |
| M3 | Manual source sync, own login, documents and optional mail | pending |
| M4 | Existing views, reader, comparison and text assistant | pending |
| M5 | Reminders, optional speech and authenticated local MCP | pending |
| M6 | Windows/Linux packages and short onboarding | pending |
| M7 | Independent review and real package/browser checks | pending |
| M8 | Human quickstart, verified artifacts and release | pending |

No external source write actions, automatic source jobs, hosted tunnels,
calendar cloud integration, mobile or macOS packages are in scope.
Tests use generated content. Account/hardware checks require the owner's
explicitly configured new installation and are reported separately.
